# The Ms of Geriatrics

One M at a time, with a Next arrow.

- **Figure 1** — the IHI Age-Friendly Health Systems **4Ms** (What Matters, Medication, Mentation, Mobility), redrawn from the IHI graphic.
- **Figure 2** — the Geriatric **5Ms** (Mind, Mobility, Medications, Multicomplexity, Matters Most; Tinetti, Huang & Molnar, *J Am Geriatr Soc* 2017;65(9):2115), redrawn from the teaching slide.
- **Figures 3–14** — one new M per figure: Money, Maintenance, Milieu, Mental, Micturition, Matters Least, Miralax, Matters Middle, Magnets, Multimorbidity, Mufasa, and the Multiverse (N ≥ 17).

Live: https://maxweiss10.github.io/geriatric-ms/

## Build

`index.html` is generated. Edit `build.py` and run:

```bash
python3 build.py
```

It writes `site/index.html` (this page) and `geriatric-ms.html` (the same page as a fragment).
